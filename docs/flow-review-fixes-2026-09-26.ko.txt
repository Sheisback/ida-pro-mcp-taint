# 2026-09-26 리뷰 보완 및 최종 검증

검토 기준은 `f16499f`이며, 이 문서는 해당 기준 이후의 보완 기록이다.
기존 OMX G001–G022 완료 기록이나 과거 Z3 측정을 현재 angr 검증으로
대체 인용하지 않는다. 자동 취약점 판정이나 지원 프로필 승격은 없다.

## 보완 내용

- **경로 질의:** 반복 블록, 지름길, 재진입, 중복·불명확한 native 주소와
  주소 없는 비어 있지 않은 블록을 명시적으로 거절한다. 실제로 빈 선형
  연결 블록만 건너뛴다. 표현하지 못하는 경로를 다른 도달성 질문으로
  바꾸지 않으며, 지원되지 않는 경우는 `unknown`으로 남는다.
- **angr 결과:** 미해결 `unconstrained` 상태를 `infeasible`로 판정하지
  않는다. 여러 성공 상태의 이력은 비교 가능한 tuple로 정렬한다.
- **배포·식별:** GUI 번들, 공통 BUILD_ID, wheel 검사, 전체 runtime
  receipt manifest에 `flow_angr`를 포함한다. capability는 엔진을 실행하지
  않고 `configured_unverified`와 실제 설정 오류를 구분한다.
- **wire:** v2의 큰 상수는 tagged integer를 유지한다. v1 분석 항목에 큰
  정수가 있으면 크기와 무관하게 기존 canonical-JSON chunk 형식을 쓴다.
  메모리 범위의 끝값이나 저장된 근거를 삭제·축소하지 않는다.
- **분석 근거 연결:** SSA·plan·result·선택한 Load/Store를 함께 검증한다.
  snapshot이 생성한 메모리 정보가 추가된 SSA는 원본 plan에서 정확히
  재계산한 결과와 일치해야 한다. 다른 함수·변형된 그래프·누락된 접근은
  거절하며, 정당한 원본/보강 그래프 조합은 그대로 지원한다.
- **타입·테스트 정리:** 이미 보장된 계약을 명시적으로 좁히고, 실패한
  reviewed-call native 검사도 소유한 세션을 `save=False`로 닫는다.

## 유지한 경계

- 대상 프로그램은 네이티브 실행하지 않았다. 원본 fixture 해시는 그대로이며,
  IDA는 일회용 복사본으로 검사했다.
- 기록된 과거 taint 기준선과 성능 기준값은 덮어쓰지 않았다.
  `taint_scenarios_native.json`은 그 문서에 명시된 수정 전 기준선이다.
- 현재 angr 경로 지원은 여전히 x64의 표현 가능한 prefix에 한정된다.
  보수적 거절로 커버리지가 줄 수 있으며, memory refinement는
  `evidence_only`이고 이전 inline/Z3 엔진은 되살리지 않았다.
- 실제 GUI semantic execution, 전체 ISA 재측정, protected Linux release CI와
  공식 성능 게이트의 성공을 이 로컬 검증으로 주장하지 않는다.
