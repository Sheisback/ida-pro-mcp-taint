Pointee / Store 기능 검증 — 2026-09-25
====================================

범위
----
- 선택한 entry/Load 포인터 정의 직후의 명시적 byte-range source.
- 바이트별 overwrite, scalar/memory phi, endian, alias/unknown 보존.
- 범용 Store의 base+offset, 포인터 폭, 함수 entry, 선택적 IDB 필드/배열 레이아웃 증거.
- 외부 함수 규칙, WDM 하드코딩, 자동 취약점 판정, 대상 실행 없음.

기존 검증 부채 — 테스트를 약화시키거나 해시만 고치지 않음
------------------------------------------------------
변경 전 HEAD를 별도 임시 worktree에서 검사해 아래 3개 실패가 이미 존재함을 확인했다.

1. test_public_reviewed_runtime_receipt_is_current:
   기존 G011 public runtime receipt의 BUILD_ID가 변경 전 코드와도 불일치.
2. test_static_ida_call_receipts_pin_catalog_runtime_and_replay:
   기존 call extraction receipt의 extractor hash가 변경 전 extractor와도 불일치.
3. test_actual_ida_receipts_are_fresh_repeatable_and_input_preserving:
   기존 public sample receipt의 extractor hash가 변경 전 extractor와도 불일치.

G011 public runtime의 실제 재실행도 시도했으나 기존 flow-wire/1 출력에서
unsafe_integer_for_wire_v1로 멈췄다. 숫자 반올림, 안전 검사 제거, 구 receipt 해시
교체, reviewed summary 임의 승격으로 통과시키지 않았다. 이 기존 corpus/summary
갱신은 이번 범용 source/Store 기능과 별도 작업이다.

남은 한계
---------
- 실제 Windows 드라이버/커널·TLS·MMIO 검증 아님. flat-address 모델 가정을 기록함.
- IDB 타입 정확성과 analyst_assumed_exact 포인터 유효성은 분석자 가정.
- callback 증거는 Store 실행 지점의 조건부 관계이며 경로 도달성, 모든 경로 등록,
  후속 덮어쓰기 없음, 실제 callback 실행을 증명하지 않음.
- 미해결 Load/spill, 다른 phi 값, 잘림, 불확실한 효과는 unknown/partial 유지.
